Integración con la interfaz 3D

La recreación 3D del estanque y esta interfaz hablan por HTTP. Sirve cualquier tecnología del lado 3D: Three.js, Babylon, Unity WebGL u otra app Rails. Hay tres caminos, y se pueden usar juntos.

1. El 3D envía sus cuadros

Cada render con su verdad (peces con largo y peso, pellets con su estado) entra como dataset sintético. Con ?predict=1 se corre el detector y se compara con la verdad: así se mide el recall por turbidez y luz.

// desde el renderer (navegador)
const blob = await new Promise(r => renderer.domElement.toBlob(r, "image/png"));
const form = new FormData();
form.append("frame", JSON.stringify(frame));     // esquema abajo
form.append("image", blob, `${frame.camera.id}_${frame.frame_id}.png`);
await fetch("http://127.0.0.1:3800/api/v1/sim_frames?predict=1", {
  method: "POST", body: form
});

2. El 3D lee lo medido por las cámaras

GET /api/v1/tank_state devuelve el último peso medio, el % de alimento no consumido y la grilla de pellets del fondo en coordenadas del estanque. El 3D puede pintar esas celdas sobre el fondo cónico y mostrar lo simulado junto a lo medido.

const s = await (await fetch("http://127.0.0.1:3800/api/v1/tank_state")).json();
// s.weight.data.mean_weight_g, s.uneaten.data.uneaten_pct
const g = s.bottom_grid?.data;                    // {cell_m, origin_m:[x0,y0], grid:[[n,…],…]}
g?.grid.forEach((row, j) => row.forEach((n, i) => {
  const x = g.origin_m[0] + (i + 0.5) * g.cell_m;
  const z = g.origin_m[1] + (j + 0.5) * g.cell_m;
  const y = -depth + (radius - Math.hypot(x, z)) * 0.05;   // fondo 1:20
  paintCell(x, y, z, n);                                    // función del 3D
}));

API

GET/api/v1/healthEstado, servicio de visión, datasets y cuadros
GET/api/v1/tank_stateÚltimo peso, alimento no consumido, grilla del fondo, agua
GET/api/v1/datasetsDatasets con su formato, licencia y conteos
GET/api/v1/datasets/:idImágenes reales con URL y etiquetas normalizadas
GET/api/v1/runsCorridas de modelos con métricas
GET/api/v1/runs/:idPredicciones y emparejamiento por imagen
POST/api/v1/sim_framesCuadro del 3D (multipart frame + image, o JSON con image_base64)
GET/api/v1/sim_framesÚltimos cuadros recibidos
POST/api/v1/measurementsMedición de cámaras: weight_summary, uneaten, bottom_grid, water
POST/api/v1/predictReenvía una imagen al servicio de visión (task=fish|pellet|stereo)

Escrituras no requieren (definir SALMOSONAR_API_TOKEN para exigir) Authorization: Bearer <token>. CORS: *.
